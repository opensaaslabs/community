# OpenSaaSLabs Community

OpenSaaSLabs Community is the free public resource tier of OpenSaaSLabs.

It helps people learn, evaluate, and adopt enterprise software with confidence through public, reusable, community-driven resources.

## Source of Truth

The canonical OpenSaaSLabs ecosystem boundary is defined in `opensaaslabs/foundation`.

Community follows the foundation model:

```text
One Platform
Two Tiers
One Shared Data Model

Community = free public resources
Enterprise = organization-focused educational enablement
Platform = shared data model and software adoption intelligence base
OpenSaaSApps = managed services and delivery
```

## Purpose

Make practical enterprise software knowledge freely available to individuals, SMBs, teams, institutions, builders, buyers, and sellers.

## Free Resources

This repository is for public, reusable resources such as:

- software category explainers
- basic tool evaluation guides
- open checklists
- public maturity models
- adoption playbooks
- beginner training material
- community reviews
- public templates
- open-source alternatives
- implementation lessons

## Boundary

Community resources are free and public.

Organization-specific enablement material, security posture evaluations, benchmark reports, vendor questionnaires, and structured buyer or seller training packages belong in `opensaaslabs/enterprise`.

Shared schemas, maturity models, recommendation models, and catalog models belong in `opensaaslabs/platform`.

Managed services, hosting, implementation, app maintenance, and operations belong in OpenSaaSApps.

## North Star

Right software. Right stage. Right use case. Right maturity. Confident adoption.
